# ملخص مشروع PharmaChain - نظام إدارة الصيدليات

## نظرة عامة

تطبيق **PharmaChain** هو نظام متكامل لإدارة الصيدليات مبني بتقنية Flutter مع Firebase كخلفية (Backend). يدعم التطبيق اللغتين العربية والإنجليزية ويعمل بالوضع الفاتح والداكن.

---

## الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| لوحة التحكم (Dashboard) | عرض ملخص شامل لأداء الصيدلية |
| إدارة المخزون (Inventory) | تتبع المخزون وتنبيهات النواقص وسجل الحركات |
| إدارة الأدوية (Medications) | قاعدة بيانات الأدوية مع التفاصيل الكاملة |
| نقطة البيع (Sales & POS) | تسجيل عمليات البيع مع طرق دفع متعددة |
| الوصفات الطبية (Prescriptions) | إدارة الوصفات الطبية وربطها بالمبيعات |
| طلبات العملاء (Customer Orders) | تتبع طلبات العملاء وحالاتها |
| الموردين (Suppliers) | إدارة بيانات الموردين |
| أوامر الشراء (Purchase Orders) | إنشاء وتتبع أوامر الشراء من الموردين |
| الموظفين (Staff) | إدارة بيانات الموظفين |
| الورديات (Shifts) | جدولة ورديات العمل |
| الفروع (Branches) | إدارة فروع الصيدلية المتعددة |
| التقارير (Reports) | تقارير المبيعات والمخزون والأداء |

---

## التقنيات المستخدمة

- **Flutter** (SDK ^3.11.5)
- **Firebase** (Auth + Firestore)
- **flutter_bloc** (إدارة الحالة)
- **go_router** (التوجيه)
- **get_it + injectable** (حقن التبعيات)
- **freezed** (نماذج البيانات غير القابلة للتغيير)
- **flutter_screenutil** (التصميم المتجاوب)
- **QR Code** (مسح وإنشاء رموز QR)

## البنية المعمارية

يتبع المشروع هيكلة Clean Architecture:

```
lib/
├── core/           → الأدوات المشتركة والثيمات والتوجيه
├── features/       → كل ميزة منفصلة
│   ├── data/       → مصادر البيانات والنماذج والمستودعات
│   └── presentation/ → الشاشات والـ Cubit والويدجت
└── app.dart        → ويدجت التطبيق الرئيسي
```

## نصائح لتحديث التطبيق

### 1. تحسين الأداء
- أضف **pagination** (تحميل تدريجي) للقوائم الطويلة بدلاً من تحميل كل البيانات دفعة واحدة
- استخدم **Firestore caching** لتقليل عدد القراءات وتحسين السرعة عند عدم وجود إنترنت
- أضف **lazy loading** للشاشات باستخدام `AutoRoute` أو تحميل الميزات عند الحاجة

### 2. تحسين تجربة المستخدم
- أضف **بحث ذكي** شامل يبحث في الأدوية والعملاء والوصفات من مكان واحد
- أضف **إشعارات push** لتنبيه المستخدم عند انتهاء صلاحية الأدوية أو نقص المخزون
- أضف **وضع عدم الاتصال** (Offline Mode) الكامل مع مزامنة عند عودة الاتصال
- حسّن واجهة نقطة البيع لتكون أسرع باستخدام اختصارات لوحة المفاتيح

### 3. ميزات جديدة مقترحة
- **نظام صلاحيات** (Roles & Permissions): مدير، صيدلي، كاشير - كل واحد يرى ما يخصه
- **تتبع تواريخ الصلاحية**: تنبيهات تلقائية للأدوية القريبة من الانتهاء
- **ربط مع أنظمة التأمين**: لتسهيل معالجة وصفات التأمين الصحي
- **تطبيق عميل**: تطبيق منفصل للعملاء لطلب الأدوية وتتبع طلباتهم
- **لوحة تحليلات متقدمة**: رسوم بيانية للمبيعات اليومية/الشهرية مع مقارنات
- **نظام ولاء العملاء**: نقاط وخصومات للعملاء المتكررين
- **ماسح الباركود المحسّن**: ربط مباشر بقاعدة بيانات الأدوية عند المسح

### 4. تحسينات تقنية
- أضف **اختبارات الوحدة** (Unit Tests) للـ Cubits ومصادر البيانات
- أضف **CI/CD** مع GitHub Actions وFirebase App Distribution
- انقل إلى **Firebase Security Rules** محكمة لحماية البيانات
- أضف **Crashlytics** لتتبع الأخطاء في الإنتاج
- فكّر بالانتقال إلى **Supabase** إذا احتجت استعلامات SQL معقدة للتقارير
- أضف **flavors** (dev, staging, production) لفصل بيئات التطوير

### 5. تحسين الكود الحالي
- راجع الملفات الكبيرة وقسّمها إلى ويدجت أصغر (لا يتجاوز 150 سطر)
- تأكد من عدم وجود استدعاءات Firebase في طبقة العرض (Presentation)
- استخدم `ErrorMapper` موحد لمعالجة الأخطاء بدلاً من التكرار
- أضف مفاتيح الترجمة المفقودة في ملفات اللغة

### 6. الأمان
- فعّل **Firebase App Check** لمنع الوصول غير المصرح
- شفّر البيانات الحساسة محلياً باستخدام `flutter_secure_storage`
- أضف **تسجيل دخول ثنائي** (2FA) للمدراء
- راجع قواعد Firestore Security Rules بشكل دوري
